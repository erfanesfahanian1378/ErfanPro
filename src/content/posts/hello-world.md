I've wanted a small place on the web for a while: somewhere to keep an up-to-date CV, list the things I've built, and write down what I learn along the way.

This site is deliberately simple. It's a static site built with [Astro](https://astro.build), every post is a Markdown file in the repository, and it's served from Cloudflare's network for free. Publishing a post is just a commit:

```bash
git add src/content/posts/my-new-post.md
git commit -m "New post"
git push
```

Expect notes on back-end engineering, integrations and automation, and now and then a game or AI experiment from university.
